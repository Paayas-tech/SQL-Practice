# PostgreSQL PL/pgSQL and Triggers

This project contains practical examples from my PostgreSQL learning covering PL/pgSQL, variables, loops, conditionals, trigger functions, triggers, INSTEAD OF triggers and permissions.

## Topics Covered

- PL/pgSQL basics
- DO blocks
- FOR loops
- RAISE NOTICE
- RAISE EXCEPTION
- Variables
- SELECT INTO
- RECORD type
- IF / ELSE conditionals
- Trigger functions
- BEFORE INSERT triggers
- NEW and OLD records
- Modifying data before insertion
- INSTEAD OF DELETE triggers
- Views
- Soft deletes
- PostgreSQL permissions
- SECURITY DEFINER
